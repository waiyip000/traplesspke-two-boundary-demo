# Reporting implementation issues

This is an inspectable reference demonstration. Do not protect production secrets
with the experimental demo or disclose reusable keys in a public report.

Report functional problems through this repository's GitHub Issues using disposable
synthetic inputs, the demo version, command and observed error. Do not upload owner
directories, passwords, unrevealed truth or unrelated private material. No private
reporting channel is asserted unless the owner separately enables one.

Local commitment/submission/reveal records do not provide a remote decryption or
guess-confirmation service. Functional controls and closed teaching examples are
separate from independently exchanged blinded evidence.
