- Inspectable Python composition with independent ML-KEM-768 capabilities,
  AES-256-GCM-SIV and HKDF-SHA256.
- Password-protected reusable identity, public-only sender, private receiver,
  selected-path confirmation and actual encrypt/recover/compare walkthrough.
- Three observation exports, content-only recovery and local blinded-record
  exchange with commitment checking and descriptive scoring.
- Stage-bound recovery, non-overwriting output and Windows stable reads.
- Offline Windows x64 / CPython 3.12 kit and dependency notices.
- Apache-2.0 for the demo source; commercial implementation excluded.

remains TBDEMO1. Local clock checks do not attest independent peer ordering.

resistance, OS confinement or constant-time Python result is claimed.
