# Demonstration 0.1.4

Corrected and functionally validated for its stated demonstration purposes:
public-key selection and exact recovery, examination of the content/intent
boundary, and independent expert understanding, testing and attacks on the
disclosed construction. Corrections address input admission, file routing,
capability checks, recovery state and installation integrity.

The core mathematics, primitives and TBDEMO1 wire format are unchanged.
Apache-2.0 remains the source licence. Functional validation does not establish
cryptographic security. See [PROTOCOL.md](PROTOCOL.md), [THREAT_MODEL.md](THREAT_MODEL.md),
[LIMITATIONS.md](LIMITATIONS.md) and [VALIDATION.md](VALIDATION.md).
